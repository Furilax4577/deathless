# Wiki de Deathless

Le wiki fixe les règles du jeu : les pages sources sont dans `pages/` (Markdown), le site généré dans `site/` (non versionné).

- **Consulter** : double-clic sur `ouvrir-wiki.cmd` (génère le site puis l'ouvre dans le navigateur). Python 3 suffit, aucune dépendance.
- **Modifier** : éditer un fichier de `pages/`, puis relancer `ouvrir-wiki.cmd`. L'ordre du menu est dans `build.py` (`MENU`).
- **Étiquettes** : `{décidé}`, `{à confirmer}`, `{effet validé}` ; pastille de couleur : `{couleur #rrggbb}`.
- Publication : en local pour l'instant (décision du 25/09/2026).
